## A. Valuation context  ★ highest leverage (data already unblocked)
Problem: we now fetch live PE/PB/mkt-cap per name, but the report shows raw
numbers with no context. "SMIC 198x PE" means nothing without history/peers.
Add:
- **Valuation history percentile**: pull a PE/PB time series per featured name
  (chinadata or AKShare valuation history / stock_value_em has a dated series),
  compute current value's percentile over 3-5y. Output "PE 198x = 92nd pct".
- **Peer/sector relative**: rank each name's PE/PB vs its theme peers (we already
  have the universe grouping). Output z-score or quartile within theme.
- **Cheap+improving quadrant**: cross valuation percentile with an earnings or
  trade-momentum signal to flag the actionable quadrant.
Interlink: add a "VALUATION CONTEXT" block to sectorDigest; deck theme slide gets
a small PE/PB-percentile table. House view can cite it for sector stance.
Effort: medium. Risk: need a per-name valuation *history* endpoint (verify
stock_value_em returns history, else use chinadata/another series).

## B. Earnings & estimates layer
Problem: report has macro + price + valuation, but no fundamentals trajectory.
Add (per featured name, A-share, via AKShare from HK box):
- Revenue/EPS growth (stock_financial_analysis_indicator / financial abstract).
- Earnings momentum: latest YoY growth + trend (accelerating/decelerating).
- (Stretch) consensus estimates / revisions if any free source from HK.
Interlink: "FUNDAMENTALS" line per name in sectorDigest; deck name callouts.
Effort: medium. Risk: AKShare financial endpoints' reliability from HK (verify;
some are EastMoney push2-style — probe like we did for valuation).

## C. Flow & positioning
Problem: no "what is the money doing" signal. The veterans (Druckenmiller, Marks)
demand positioning context.
Add (mostly already reachable):
- **Northbound / Stock Connect flows** (HKEX client already exists) — monthly/
  cumulative net buy, by direction.
- **Sector fund flows** (sidecar /sector/flows — works from HK, intermittently) —
  top inflow/outflow sectors.
- **Margin balances** (AKShare margin functions) if reachable.
Interlink: new "FLOWS & POSITIONING" digest section in report context; deck gets
a flows slide. Anomaly/regime banner can flag positioning extremes.
Effort: medium (Northbound is low-hanging; margin needs a probe).

## D. Policy → sector → name transmission (deepen existing)
Problem: Policy Tracker and themes exist but aren't explicitly chained into a
causal narrative. A 45-min deck needs a spine.
Add:
- A transmission mapper: for each top policy item, link policy -> affected
  theme(s) -> the live trade/valuation evidence -> named beneficiaries/losers.
  (We already tag policy items with themes and have per-theme trade + valuations
  — this is mostly a synthesis-prompt + structured block, not new data.)
Interlink: "POLICY TRANSMISSION" block fed to the LLM; deck gets a transmission
diagram/table per major policy. Strongest narrative upgrade per unit effort.
Effort: low-medium (prompt + structuring; reuses existing data).

## E. Scenario / risk framing  ★ second-highest leverage
Problem: no explicit bull/base/bear or falsification — institutional decks live
on the risk section. Thesis-critic mode already generates bear cases; formalize.
Add:
- **Per-theme scenario table**: bull/base/bear with explicit triggers and
  price/earnings implications, generated by the strongest model; bear case uses
  the red-team personas (marks/pettis/collier/druckenmiller).
- **Falsification list**: "what would prove this thesis wrong" per theme.
- **Risk dashboard**: export-control escalation, property drag, CNY, liquidity —
  scored, with the live series as evidence.
Interlink: new scenario/risk sections in the report + dedicated deck section
(3-5 slides). Uses existing personas + data; mostly synthesis structure.
Effort: medium. Highest analytical payoff alongside A.

## F. Relative & global context
Problem: China shown in isolation; PM needs "why China / why now".
Add:
- **A vs H premium** (AH premium) — A-share vs HK dual-listed (have both prices).
- **China vs EM vs DM** equity + **USD/CNY + UST yields** overlay (have cross-asset).
- Optional: China weight/positioning vs benchmark.
Interlink: "RELATIVE CONTEXT" block + a deck slide; frames the top-down call.
Effort: low-medium (mostly recombining series we already pull).

1. **A — valuation context** (data just unblocked; turns numbers into decisions).
2. **E — scenario/risk framing** (institutional necessity; reuses personas).
3. **D — policy transmission** (narrative spine; low data cost).
4. **C — flows/positioning** (Northbound is quick; high signal).
5. **F — relative context** (recombine existing series).

Each is independently shippable and interlinks into both the strategy note and
the 45-minute deck. Recommend doing A + E first as a paired "decision layer"
upgrade, then D for narrative, then C/F/B as data permits.
